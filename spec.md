# Lviv Touristic Agency - Website Specification

## Project Overview
**Company Name:** Lviv Touristic Agency
**Address:** Eugen Mlanyuka 4 st.
**Sector:** Travel and Tourism (Registered Travel Agency)
**Objective:** Create a premium, responsive static website without using JavaScript.

## Technical Requirements
- **Languages:** HTML5, CSS3 (Vanilla)
- **JavaScript:** strictly prohibited.
- **Responsiveness:** Must work seamlessly on mobile, tablet, and desktop devices.
- **Styling:** Premium aesthetic utilizing modern web design trends like glassmorphism, smooth gradients, high-quality typography, and CSS-based micro-animations (hover effects, transitions).

## Structure
### 1. Header & Navigation
- Branding/Logo area.
- Navigation links pointing to page sections (Home, About, Services, Contact).

### 2. Hero Section
- Engaging background visual related to Lviv/tourism.
- Prominent headline and subheadline.
- Call to Action (CTA) button.

### 3. About Section
- Brief description of the agency.
- Highlighting the agency's expertise in the travel sector.

### 4. Services/Tours
- Grid layout showcasing popular travel packages or tours.
- Hover effects for premium feel.

### 5. Contact Section & Footer
- Contact form (styled with CSS, no JS functionality).
- Display of physical address: Eugen Mlanyuka 4 st.
- Additional generic contact info (phone/email placeholders).
- Footer copyright and links.

## Design Guidelines
- **Color Palette:** Deep blues, bright gold/yellow accents, and clean white/light gray backgrounds to evoke trust and premium travel.
- **Typography:** Modern sans-serif (e.g., 'Inter', 'Roboto') imported from Google Fonts.
- **UI Elements:** Rounded corners, subtle drop shadows, glassmorphism for overlapping elements.
